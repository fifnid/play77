# Крутка — Испытай удачу

Небольшая браузерная игра с колесом фортуны. Крути колесо, собирай очки и побей свой рекорд. Прогресс сохраняется в браузере.

## Запуск

Открой `index.html` в браузере. Никакие зависимости и сборка не нужны.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи в него `index.html` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Через минуту игра будет доступна по ссылке вида `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Локально сохранённые очки привязаны к браузеру и устройству.
